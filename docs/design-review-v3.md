# 포트폴리오 디자인 v3 — 2026-10-13

## 기준
Sites의 presentation-led 디자인 가이드: 반복되는 카드보다 내용에 맞는 구성, 실제 자료 중심의 이미지, 탐색 목적에 맞는 흐름을 적용했다. Astro / GitHub Pages / GitHub Actions는 유지한다.

## 첫 수정
- 모든 페이지의 화살표를 제거했다. 링크는 밑줄, 색상 변화, 키보드 포커스로 식별한다.
- 포스터의 바깥 박스를 제거하고 원본 비율을 유지했다.
- 한국어 헤드라인과 영문 세리프 제목의 대비, 비대칭 프로젝트 배치로 시각적 리듬을 만들었다.
- 상세 페이지의 포스터 크기와 위치, 본문 폭, 문단 간격을 조정했다.

## 화면 평가 후 재수정
데스크톱 첫 화면에서 포스터가 과도하게 커지고 캡션이 작아 보였다. 포스터 폭을 최대 420px로 제한하고 상단 간격을 줄였다. 설명과 캡션 크기를 키웠다. 모바일은 별도 간격과 단일 열을 사용한다.

## 검증
320, 768, 1440px × 4페이지에서 가로 넘침 없음. 모든 페이지 H1 한 개, 화살표 문자 없음. 빌드 및 내부 링크/파일 검사 통과. Lighthouse 결과는 lighthouse-local-v3.json에 기록한다. 자동 검사는 모든 사용자의 미적 만족이나 수동 접근성 검증을 대신하지 않는다.
