- https://kuadarchive.com/2026/ : 전시의 시각적 표현과 실제 대주제 포스터를 유지했다.

## 반복 1 — 구조 재설계
기존 큰 영문 이름과 긴 빈 공간이 대표 작업을 아래로 밀어냈다. 소개와 대표 작업을 나란히 배치하고 한국어를 중심으로 역할을 먼저 설명했다. 이름은 헤더에서 식별하고 포스터는 첫 화면에서 보게 했다. KUAD 외 RAG·비전 프로젝트를 노션의 확인 가능한 기여 범위로 추가했다.

## 반복 2 — 화면과 탐색
390px 모바일에서 세로 흐름을 확인하고 320/768/1440px의 네 페이지를 검사했다. 모든 검사에서 가로 넘침이 없었다. 긴 KUAD 페이지에 개요·운영·성능·공개 이후 목차를 추가했다. 성능 수치는 측정 조건과 함께 제공하며 펼치기로 상세 한계를 확인할 수 있다. RAG·비전 표지의 도식은 실제 화면 캡처가 아닌 구조 재구성·개념도라고 명시했다.

## 반복 3 — 접근성과 성능
첫 Lighthouse에서 4개 주요 카테고리가 모두 100점이었지만 비점수 항목에 보이는 문구와 접근성 이름 불일치가 나타났다. 시각 링크의 별도 aria-label을 제거해 실제 내용으로 접근성 이름을 구성했다. 원본 포스터는 보존하고 480/768px WebP를 제공했다. 외부 폰트와 불필요한 클라이언트 JavaScript 없이 구성했다. robots.txt, sitemap, canonical을 추가했다.

## 재현
Lighthouse 13.5.0, 설치된 Chrome, 모바일 기본 시뮬레이션 및 desktop preset. 배포용 정적 빌드를 로컬 HTTP 서버에서 측정했다. 각 페이지·기기별 단회 검사이며 실사용자 통계와 다르다. 실제 공개 URL은 배포 후 추가 검사한다. 100점은 해당 실행의 결과이며 모든 환경의 보장은 아니다. 자동 접근성 검사는 수동 스크린리더 검증을 대체하지 않는다.
