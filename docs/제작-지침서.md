# 정제영 포트폴리오 제작 지침 v0.1

작성일: 2026-10-12

## 목적과 범위
실제 서비스를 만들고 운영한 경험을 채용 담당자와 협업 상대가 이해하도록 한다. 첫 버전은 홈과 KUAD 상세 페이지다. 확인되지 않은 다른 프로젝트나 연락처를 임의로 추가하지 않는다.

## 시각 기준
KUAD 2026 홈·프로젝트 화면을 직접 확인했다. 흰 배경, 넓은 여백, 단순한 탐색, 작품 중심의 구성을 참고한다. 포트폴리오는 따뜻한 백색과 짙은 먹색, 큰 이름, 가는 구분선, 편집형 배치를 사용한다. 반복되는 둥근 카드, 그라데이션, 장식 아이콘, 자동재생 영상, 스크롤을 가로채는 효과는 사용하지 않는다. 모바일에서는 글과 작업 이미지가 자연스럽게 한 열로 이어져야 한다.

## 콘텐츠 원칙
노션의 사실 기록에 근거해 편집한다. 2024 Vue / 2025 React / 2026 React를 구분한다. 2024·2025는 팀 프론트엔드, 2026은 단독 풀스택·운영이다. 인수인계는 준비로 표기하고 완료라고 주장하지 않는다. 성능 수치에는 측정 날짜·범위·조건을 함께 표기한다. 초기 로컬 실험과 운영 배포 후 측정을 섞지 않는다. 품절 기능은 운영진 요청 이후 관리자가 직접 설정할 수 있게 구현한 것으로 설명한다. 전시 작품과 포스터 제작은 각 참여 팀의 기여로 구분한다.

## 구조
- 홈: 이름과 소개 → KUAD 대표 작업 → 개발 관점과 GitHub.
- KUAD: 개요 → 연도별 역할 → 운영 기능 → 성능 개선과 조건 → 배포·유지보수.
- 확인된 연락처와 다른 프로젝트는 후속 버전에서 추가한다.

## 구현과 운영
Astro 정적 출력, 기본 CSS, JavaScript가 필요 없는 탐색을 사용한다. Node.js 22를 권장한다. 이미지 파일은 로컬에 보관해 외부 핫링크 의존을 없앤다. GitHub 저장소는 jayyeong/jayyeong.github.io이며 GitHub Pages 기본 주소로 배포한다.

GitHub Pages용 워크플로는 PR에서 빌드와 내부 링크·이미지를 검사하고 main 반영 시 배포한다. Pages 소스는 GitHub Actions다. SITE_URL과 BASE_PATH는 배포 메타데이터로 전달한다. 공개 저장소와 기본 github.io 주소로 무료 운영을 시작한다. 도메인 구매는 별도다.

## 검증 기준
홈·상세 페이지 빌드 성공, 모바일/데스크톱 가로 넘침 없음, 이미지 로딩, 주 메뉴·프로젝트 이동·목록 복귀·상단 이동·측정 조건 펼치기 확인. 키보드 포커스와 본문 바로가기를 제공한다. 실제 수행한 검증만 완료라고 기록한다.

## AI 협업
자료 근거 확인 → 작고 완성된 화면 구현 → 사용자 피드백 → 필요한 수정 순서로 진행한다. 개인 자료 전체를 공개하지 않고 공개 문안에 필요한 사실만 선별한다. 기술 선택과 편집 판단은 AI가 제안하되 추측을 경력·수치로 확정하지 않는다.
